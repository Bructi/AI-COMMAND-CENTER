📡 OpenAI-Compatible API Endpoint

Use this local endpoint as a drop-in replacement for OpenAI API in Hermes, Cursor, Cline/OpenCode, LangChain, or custom Python/Node scripts.

omni-fast omni-code omni-reason omni-vision omni-agent omni-free omni-best
🤖 Hermes AI Agent Config
{
  "provider": "custom",
  "base_url": "http://localhost:3000/v1",
  "api_key": "YOUR_LOCAL_KEY_OR_DUMMY",
  "model": "omni-code",
  "fallback_model": "omni-fast"
}
🐍 Python SDK Snippet
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="none"
)

response = client.chat.completions.create(
    model="omni-fast",
    messages=[{"role": "user", "content": "Hello Command Center!"}]
)
print(response.choices[0].message.content)
⚡ cURL Command
curl -X POST http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "omni-fast",
    "messages": [{"role": "user", "content": "Explain binary search in 1 sentence."}]
  }'
